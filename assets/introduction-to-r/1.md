I. Overview of R : R’s Interface
1. Source / Script Editor (Top Left) This is where we write, edit, and save our code. Always write your code here
so you have a reproducible record of your work! (You can put your cursor on a line and press Ctrl + Enter or Cmd
+ Return to run it).
2. Console (Bottom Left) This is where R actually executes your code and prints the text output. You can type
quick commands directly in here, but the code will not be saved when you close the program.
3. Environment (Top Right) R only knows what it has actively memorized. This pane shows every dataset,
variable, and value you have loaded. If you don’t see your data listed here, R doesn’t know it exists.
4. Files, Plots, & Help (Bottom Right) This is where your visualizations will appear (Plots), where you can view
your computer’s folder structure (Files), and where official R documentation will open (Help).

the program.

where you left off.

assignments.
Ultimate Portability: Uses relative file paths, meaning you can zip the folder, send it to a collaborator, and

IV. Piping in R
The Magic of the Pipe
If there is one concept that defines modern R programming, it is the pipe.
The pipe is a connective operator that passes the result on its left into the function on its right. Whenever you
see a pipe in R, read it out loud as “…and then…”
Traditional R code evaluates from the inside out, creating a nightmare of nested parentheses. The pipe unwraps
this, letting you read and write sequentially from top to bottom.
Consider a morning routine. Without the pipe (Inside-Out):
With the pipe (Left-to-Right):
The pipe simply passes “you” through a logical sequence of actions.
You will see two different pipe symbols in the wild. They do the exact same thing:
%>% (The Magrittr Pipe): The original pipe popularized by the Tidyverse. It requires loading packages like
dplyr to work.
|> (The Native Pipe): Built directly into R (Version 4.1+). It requires no extra packages and is the modern
standard. We will focus on this one.
Because |> is built into R, you can use it to instantly clean up standard base R operations.

Example 2: Hidden Groups (Histograms & Faceting)
Sometimes, looking at the entire population hides crucial details. We can use layers and facets to solve data
mysteries.
If we just plot a histogram of adult height, the resulting bell curve looks unusually wide and a bit lumpy.
Result: A single, wide mountain of data. Why not a bell curve?
By adding fill = Gender to our aesthetics, we instantly reveal the two distinct bell curves corresponding to two
distinct populations hiding inside that single mountain.
While overlapping colors are nice, they can sometimes be hard to read. The most powerful layer in ggplot2 is
the facet. By adding facet_wrap(~ Gender) , we tell R: “Take this entire chart, and split it into separate side-byside plots by Gender.”
